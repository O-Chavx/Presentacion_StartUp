# Conversaciones con usuarios potenciales

Aquí van las notas de las 3 conversaciones (una por archivo: `01_logistica.md`, `02_contabilidad.md`, `03_residente_obra.md`). Se citan solo con el cargo y el tipo de empresa, salvo que la persona haya dado permiso para usar su nombre.

## Guía de preguntas

1. ¿Cuántas facturas de proveedores revisan en un mes? ¿Cuántas obras a la vez?
2. La última vez que revisaste una factura, ¿con qué la comparaste?
3. ¿Cuánto tiempo te toma revisar una factura completa?
4. ¿Dónde lo registran hoy? (Excel, ERP, correo, WhatsApp, archivador)
5. ¿Cuándo fue la última vez que algo no cuadró? ¿Qué fue?
6. ¿Cuánto costó ese error, en soles o en tiempo?
7. ¿Revisan si el proveedor está activo y habido en la SUNAT, o sancionado por el OSCE?
8. ¿Han tenido problemas por facturas de proveedores no habidos?
9. Si una herramienta hiciera este cruce en un minuto, ¿la usarías? ¿Cuánto pagarías al mes?
